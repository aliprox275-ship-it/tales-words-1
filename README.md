# Tales & Words

تطبيق ويب ثابت (Static PWA) لتعليم الإنجليزية والألمانية بالقصص القصيرة مع ترجمة عربية.

## المزايا

- 176 قصة (EN/DE — مستويات A1/A2)
- بنك مفردات 1800 كلمة لكل لغة
- الصوت: TTS من جهاز المستخدم (speechSynthesis) — لا توجد ملفات صوت مسجلة
- يعمل بدون إنترنت بعد أول تحميل (Service Worker)

## البنية الحالية

- `index.html` — الواجهة + البيانات + المنطق الأساسي
- `sw.js` — Service Worker لتحديث الكاش والدعم الآلي للأوفلاين
- `manifest.webmanifest` — الملف الأساسي لبيانات تثبيت الـPWA
- `assets/manifest.webmanifest` — نسخة موازية متطابقة للامتثال لبعض البيئات القديمة
- `assets/icons/` — أيقونات التطبيق
- `assets/img/` — أغلفة القصص

## قاعدة مهمة عند أي تعديل

ارفع قيمة `VERSION` في `sw.js` مع كل تحديث (مثلًا v5 → v6)،
وإلا تبقى الأجهزة على النسخة القديمة من الكاش.

## النشر

الموقع مربوط بـNetlify: أي **push** إلى `main` ينشر تلقائيًا.
لا توجد خطوة بناء — الملفات تُنشر كما هي (`publish = "."` في `netlify.toml`).

## نقاط التطوير الموصى بها

- حذف ملفات `.gitkeep` غير الضرورية في النهاية
- تقليل تكرار صور الأغلفة إن أمكن
- فصل `index.html` إلى ملفات JS/CSS أكثر وضوحًا عبر الوقت
- إضافة فحص بسيط قبل النشر للتحقق من صلاحية الـmanifest والـSW
