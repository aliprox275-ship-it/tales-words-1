# Tales & Words

تطبيق ويب ثابت (Static PWA) لتعليم الإنجليزية والألمانية بالقصص القصيرة مع ترجمة عربية.

- 302 قصة (EN/DE — مستويات A1/A2) وبنك مفردات: EN ‏2462 / DE ‏2467 كلمة فريدة (A1 ‏EN ‏967 / DE ‏993، ‏A2 ‏EN ‏1495 / DE ‏1474)
- الأرقام تُحسب لكل لغة على حدة (معيار CEFR) — لا يُجمع EN+DE في رقم واحد
- لا يوجد تكرار بين مصدري البنك (BANK_DATA ‏A1 وBANK_DATA2 ‏A2)، ولا تكرار داخل البنك
- الصوت: تسجيلات مسجلة للقصص والبنك، مع TTS من جهاز المستخدم كبديل للعناصر المفقودة
- يعمل بدون إنترنت بعد أول تحميل (Service Worker)

## البنية

- `index.html` — التطبيق كله (واجهة + بيانات + منطق) في ملف واحد
- `sw.js` — Service Worker: كاش واجهة التطبيق والتحديثات
- `manifest.webmanifest` — بيانات تثبيت الـPWA
- `assets/icons/` — أيقونات التطبيق
- `assets/img/` — أغلفة القصص

## النشر

الموقع مربوط بـVercel: أي **push** لفرع `main` ينشر تلقائيًا.
لا توجد خطوة بناء (Build) — الملفات تُنشر كما هي. (Netlify متوقف — لا يُستخدم.)

## قاعدة مهمة عند أي تعديل

ارفع قيمة `VERSION` في `sw.js` مع كل تحديث (مثلًا v4 ← v5)،
وإلا تبقى الأجهزة على الكاش القديم ولا يصلها التحديث.

## مصدر الحقيقة

هذا الريبو هو النسخة المرجعية الوحيدة. أي تعديل يبدأ من هنا —
لا تعدّل نسخًا محلية منفصلة حتى لا تضيع التغييرات عند النشر التالي.
